** Description
:PROPERTIES:
:CUSTOM_ID: description
:END:
flexichain is a flexible sequence data structure for Bigloo scheme, ported from the original Common Lisp implementation by Robert Strandh and Matthieu Villeneuve. It provides efficient insertion and deletion operations at arbitrary positions in a sequence, making it ideal for applications like text editors, syntax analyzers, and other scenarios requiring frequent sequence modifications.

The key advantages of flexichain over traditional vectors or lists are:
- *Efficient insertion/deletion*: O(1) amortized time for insertions and deletions at arbitrary positions
- *Gap buffer implementation*: Uses a gap buffer internally for optimal performance
- *Cursor support*: Provides cursors that maintain their position even as the sequence is modified
- *Ranked elements*: Optional support for elements that know their position in the sequence

** Core Components
:PROPERTIES:
:CUSTOM_ID: core-components
:END:
flexichain provides the following main components:

*** Core API
- =<flexichain>= - Abstract base class for flexible sequences
- =<gapbuffer>= - Concrete gap buffer implementation
- Basic operations: =flexi-insert!=, =flexi-delete!=, =flexi-ref=, =flexi-set!=
- Bulk operations: =flexi-insert-vector!=, =flexi-delete-items!=
- Utility operations: =flexi-length=, =flexi-empty?=, =flexi-rotate!=

*** Cursor Support
- =<flexicursor>= - Base cursor class
- =<left-sticky-flexicursor>= - Cursor that sticks left during insertions
- =<right-sticky-flexicursor>= - Cursor that sticks right during insertions
- =<cursorchain>= - Flexichain with automatic cursor management

*** Ranked Elements
- =<element-rank-mixin>= - Mixin for position-aware elements
- =<ranked-gapbuffer>= - Gapbuffer with automatic rank management
- Navigation methods: =flexi-next=, =flexi-prev=, =flexi-first?=, =flexi-last?=

*** Error Handling
- =&flexi-position-error= - Invalid position errors
- =&flexi-initialization-error= - Construction errors
- =&flexi-incompatible-type-error= - Type mismatch errors
- =&flexi-cursor-error= - Cursor operation errors
- =&flexi-navigation-error= - Ranked element navigation errors

** Building
:PROPERTIES:
:CUSTOM_ID: building
:END:
Both the Bigloo native and jvm backends are supported. To build, execute:
#+begin_src shell
./configure --prefix=<installation path prefix>; make 
#+end_src 
where =<installation path prefix>= is the desired installation path
prefix (e.g, =/usr/local=). You usually want the path prefix to match
that used by Bigloo itself.

** Quick Start
:PROPERTIES:
:CUSTOM_ID: quick-start
:END:
#+begin_src scheme
(module test   
  (library flexichain))

  ;; Create a new flexichain
  (define chain (make-gapbuffer))

  ;; Insert elements
  (flexi-insert! chain 0 "hello")
  (flexi-insert! chain 1 "world")

  ;; Access elements
  (flexi-ref chain 0)  ; => "hello"
  (flexi-length chain) ; => 2

  ;; Delete elements
  (flexi-delete! chain 0)
#+end_src

** Performance
:PROPERTIES:
:CUSTOM_ID: performance
:END:
flexichain is optimized for scenarios with frequent insertions and deletions at varying positions:
- O(1) amortized insertion/deletion at the gap position
- O(1) random access to elements
- Automatic gap repositioning for optimal performance
- Memory-efficient single buffer storage
